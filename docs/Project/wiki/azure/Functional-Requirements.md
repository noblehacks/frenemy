## FR-FRENEMY-117 Four-agent reasoning integration review

Frenemy shall provide an opt-in integration test in which Claude Code, Codex, Grok Build, and Cline CLI each answer the same five reasoning questions at medium effort, every answer is independently scored by the other three agents, and the complete orchestration conversation plus every individual agent session is archived for human review.
Scope: layer-1+
**Acceptance Criteria:**
- [ ] Claude Code, Codex, Grok Build, and Cline CLI each produce one answer to each of the five canonical questions in TEST-FRENEMY-117, for 20 attributable answer records, and every answer invocation explicitly requests medium effort.
- [ ] Each answer is judged by each of the other three agents against the canonical question rubric. Every judgment identifies the question, answerer, reviewer, integer accuracy score from 0 through 100, and rationale. Self-judgment is forbidden.
- [ ] An answer succeeds only when all three peer judgments score it at least 50 percent accurate. The run succeeds only when all 20 answers succeed, all 60 peer judgments are present and valid, and no required invocation fails.
- [ ] Every run, whether passing or failing, produces one human-review archive containing the complete observable orchestration conversation, the complete observable transcript of every individual answer and review session, the canonical questions and rubrics, agent identity and medium-effort evidence, results, errors, timestamps, a manifest, and SHA-256 hashes. Credentials and hidden model reasoning are not collected.
- [ ] The integration test uses the existing caller-side Codex CLI path and the existing Frenemy ask_claude, ask_grok, and ask_cline read-only tools. It adds no relay tool, write-mode behavior, installer behavior, authentication behavior, or host/plugin configuration.

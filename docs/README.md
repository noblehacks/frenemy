The integration plan is tracked in QBrain as high-priority `PLAN-FRENEMY-001`.
The TODO, requirements, acceptance criteria, and use cases are maintained through
QBrain APIs. Generated exports are snapshots, not editable sources of truth.
Keep `layer-1` baseline requirements separate from the approved target `proposed-v2`
requirements when interpreting an export.

`docs/wiki.yaml` selects the project pages and generated requirement pages for wiki
export. Operational receipts under `docs/receipts/` are evidence, not product guides.
No project documentation was removed during the 2026-11-04 refresh.

## Interpretation limits

The output cap is JavaScript string length, not exact bytes. Stderr can exceed its nominal cap by the last appended chunk. Timeout/output failure kills the immediate child, not a proven owned process tree. Four is a per-relay-process concurrent limit; excess calls are rejected, not queued. Write mode uses the startup checkout directly. CLI flags show intended permissions, not independent proof that every external CLI version enforces them. Authentication is delegated to existing CLIs; external provider internals are not modeled.

Configuration files are user-owned data containers, not executable services. No component or code zoom is invented for passive storage. Their structures and producers/consumers are covered in installer code views and contracts. Windows/Linux/macOS deployment views are source-derived supported layouts, not receipts of live installation on those hosts.

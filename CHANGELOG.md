# 2.0.0 / Snitch 0.1.1

Version 2 is the four-seat release: Claude, Codex, agy and Kimi, any of them driving, plus Snitch. Version 1 connected Claude and Codex only.

- Snitch names the driver when Claude drives. The Claude hook recognises the Codex wrapper as Codex work, and the Claude-side wrappers name Claude as the driver when no relay host named itself. A relay host that never named itself is recorded as "unknown".
- One row per Claude chat. A chat that changed folder used to open a second row and leave the first one "running"; it now keeps the row and the name it started with.
- A Claude chat shows as working the moment a prompt is sent and closes when the chat is closed. The generated `claude-hooks.json` adds `UserPromptSubmit` and `SessionEnd` next to `PostToolUse` and `Stop`.
- A quiet chat is no longer called "No response" after five minutes. Chat rows promise a two-hour silence bound; relay consult rows keep their own watchdog bound.
- A run that stopped because a subscription or quota ran out says so in its failed row for every provider, not only Google. The native hook keeps the provider's own error text (Kimi's `StopFailure` message, captured from a real refused run), and the panel and the pop-up repeat them. Usage that ran out is named "Subscription/quota ran out". An account the provider refused (Kimi's "subscription does not have access") is named "Account refused (sign-in or plan)", because that text does not say which of the two is at fault.
- One-command install, like version 1: `bash install.sh` on Mac and Linux, `.\install.ps1` on Windows. It installs the runtime and the Snitch panel, connects every AI app it finds to the others, and adds each app's Snitch reporter. Each settings file is backed up first, only Frenemy's own entries are added or refreshed, a same-named server of the user's own is left alone, and it is safe to run twice. `--no-connect` keeps the earlier behaviour of writing the entries to `config/` only.
- The Kimi and Codex reporters now cover the same events as a working installation (Kimi: seven, including `StopFailure`; Codex: six).
- Node.js only, like version 1. Everything that runs (the installer, the relays, the helpers that start each AI app, the worker guard, the Snitch reporters and job tool) is written for Node.js 18 or newer. No Python, no shell scripts, no WSL. It is written to run on macOS, Linux and plain Windows; see RELEASE-STATUS.md for which of those were actually run.
- Found by the first test run on real Windows and Linux machines, and fixed: a prompt handed to agy or Kimi is capped at 120,000 bytes on Linux (Linux refuses one command-line argument over 128 KiB; the cap stays 200,000 on macOS); the lock no longer gives up on Windows while the last holder's folder is still being removed; stopping an app's process tree on Windows lists processes with a faster built-in command and only lists again for a survivor; the picture helper looks for its programs folder by folder in PATH order.
- Relay servers report version 2.0.0. The default install directory is `~/.local/share/frenemy/2.0.0`.

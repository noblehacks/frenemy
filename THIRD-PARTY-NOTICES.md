# Third-party names and dependencies

Claude, Codex/OpenAI, Google/Antigravity, Kimi/Moonshot, and Visual Studio Code are third-party products. Their names and identifying graphics are used to identify the connected agents, not to claim affiliation or endorsement. Provider software is not included in this archive. Users install it separately and comply with its terms.

The bridge and extension use the Node.js standard library and the VS Code extension API; they contain no bundled npm runtime dependencies. Browser test tooling is not bundled. The small brand marks in `snitch/extension/lib/brands.js` and the app logos in `images/` are shown only to identify each provider's app; they remain the property of their owners.
